# Plot gallery

Every figure on this page is generated by executable Python in [`tools/generate_plot_gallery.py`](https://github.com/stefanosbalaskas/GazeAudit/blob/main/tools/generate_plot_gallery.py). The committed SVGs are regenerated under a pinned Matplotlib environment in CI and the workflow fails on byte drift. Gallery metadata is governed separately in `_data/plots.yml`, so plot-to-method links are checked rather than duplicated by hand in this page.

## Reproduce the whole gallery

```bash
python -m pip install -e ".[plot]" "matplotlib==3.10.8"
python tools/generate_plot_gallery.py
```

The `plot-gallery` workflow regenerates the gallery and requires the working tree under `assets/plots/` to remain unchanged. The docs-site workflow also validates the generated `plot-index.json` against the governed method catalog and published SVG routes. This keeps the public figures executable and the research navigation auditable.

## Public plotting functions

The gallery is produced with the public plotting helpers `plot_qc_issue_profile`, `plot_trial_readiness`, `plot_participant_readiness`, `plot_cohort_impact`, `plot_repair_comparison`, `plot_policy_tradeoffs`, `plot_threshold_sweep`, `plot_specification_curve`, `plot_factor_sensitivity`, `plot_sensitivity_curve`, `plot_gaze_trajectory`, `plot_aoi_probability_profile`, and `plot_recovery_matrix`.
